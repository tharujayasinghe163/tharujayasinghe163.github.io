# Tharushika Jayasinghe — Mechanical Engineering Portfolio

A responsive GitHub Pages portfolio for mechanical design, CAD, robotics and engineering projects.

## Folder structure
- `index.html` — homepage
- `style.css` — site styling
- `script.js` — mobile navigation
- `projects/` — individual project pages
- `assets/` — project images and CV

## Before publishing
1. Replace the placeholder images in `assets/`.
2. Add your CV as `assets/Tharushika_Jayasinghe_CV.pdf`.
3. Replace `YOUR_EMAIL@example.com` in `index.html`.
4. Replace the LinkedIn and GitHub links with your profiles.
5. Update project descriptions with your exact contributions.
